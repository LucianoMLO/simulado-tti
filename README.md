# Simulado TTI (IBREP)
Simulador HTML de múltipla escolha (dicas + verificação com explicação e página da apostila) para a avaliação final do curso TTI.

- **Simulado Padrão:** 160 questões cobrindo todos os temas (TTI+ 120 + Avaliação/AVI 40). Sorteio de 20/40/60 ou todas.
- **Simulado Desafio:** 44 questões mais difíceis (situações-problema, cálculos, "exceto").
- Estrutura: `index.html` + `banco/*.js` (um arquivo por módulo). Plano de cobertura em `docs/PLANO_BANCO.md`.
- Para testar localmente: `py -m http.server` nesta pasta (abrir o arquivo direto não carrega `banco/`).
- Não versionar as apostilas (PDF): são material protegido do IBREP.
